# Upload the runtime assets

Follow the Arduino IDE instructions in the repository-root README.md.
Use ESP32 Dev Module, core 3.2.0, and No OTA (2MB APP/2MB SPIFFS).
Upload the sketch, then use the Arduino IDE 2 LittleFS uploader to upload this
sketch folder's complete data/ directory. Close Serial Monitor during upload.
Uploader: https://github.com/earlephilhower/arduino-littlefs-upload
